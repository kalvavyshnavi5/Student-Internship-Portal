# 🎓 Student Internship Portal

## 📌 Project Description

Student Internship Portal is a web-based application developed using Base44 AI to help students find and apply for internships. Students can search and filter opportunities, view internship details, upload resumes, submit applications, and track application status through a simple and user-friendly interface.

## ✨ Features

- Student Registration and Login
- Student Profile Management
- Internship Search
- Internship Filtering
- Internship Details
- Online Internship Application
- Resume Upload
- Application Status Tracking
- User-Friendly Dashboard

## 🛠️ Technology Used

- Base44 AI
- Web Technologies
- Database
- GitHub

## 🤖 Development Tool

This project was developed using **Base44 AI**, an AI-powered application development platform.

The main objective of this project is to provide students with a simple platform to discover suitable internship opportunities and manage their internship applications.
